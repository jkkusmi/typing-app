### Założenia podstawowe:
- Program wyświetla losowy ciąg słów, wybranych z zasobu, które użytkownik ma przepisać. Wyliczana jest średnia prędkość oraz poprawność pisania.
- Wyniki oraz ustawienia (np. limit czasowy) są zapisywane w schowku lokalnym przeglądarki.
- Konfiguracja wyboru poziomu trudności: język, słowa, zdania.

### Założenia dodatkowe:
- Stanowa (backend) tabela wyników
- Graficzne podsumowanie sesji użytkownika
